# 新官網作品圖片顯示與後台待實作規格

## 已實作：前台列表

- 首頁與作品列表共用 WorkCover，三欄排列不變。
- 移除灰底、外框圓角與 object-contain 固定圖片框。
- 原比例圖片本身套圓角，不裁切、不拉伸。透明 4:3 對齊區讓同列標題維持對齊，圖片靠底排列。
- 原圖比例不同時，上方或側面仍可能出現頁面留白，但不再有灰色圓角托底。
- 原始圖片自身若有白邊，保留原檔，不自動去邊。
- 作品內頁、資料庫、原新版、講師頁均不變。

## 後台待實作（不是已上線功能）

- 列表封面建議 1200 × 900 px、4:3；允許其他比例，保持完整顯示。
- 作品內頁圖片建議寬 1600 px 以上、高度不限；禁止為達建議尺寸強制放大低解析原圖。
- 上傳後讀取並顯示實際寬高、比例及前台預覽。
- 比例或解析度不符時只提醒，不強制裁切、不拉伸、不阻止合理長圖。
- 原檔保留；若未來需要縮圖，必須另外保存且提供預覽確認。
