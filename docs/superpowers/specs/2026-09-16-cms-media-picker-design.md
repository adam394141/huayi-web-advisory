# CMS 媒體庫選圖設計

日期：2026-09-16  
狀態：Adam 已核准直接開發  
範圍：Advisory 新官網後台 `/admin`；不包含第一網站、`/adam`、`/adam_cpc`、ADS、正式 DNS 或 `main` 合併

## 目標

讓 Adam 在編輯作品或觀點時，可以直接重用媒體庫既有的 WebP 網站版圖片，不必複製網址或重新上傳。封面選圖與內文插圖沿用同一個安全選圖視窗。

## 採用方案

在既有 Supabase 媒體索引與 `/api/cms/media` 上建立共用 Media Picker。選圖只引用既有公開網站版 URL，不搬移檔案、不建立副本、不新增資料表，也不改變既有上傳流程。

未採用方案：

- 只複製圖片網址：開發簡單，但操作仍不直覺。
- 完整素材管理系統：標籤、重新命名、刪除與批次操作超出目前 MVP，且刪除可能造成前台破圖。
- 導入外部 CMS：會形成 Supabase 與外部媒體庫的雙重管理。

## 使用流程

### 封面

1. 在封面圖片區按「從媒體庫選擇」。
2. 搜尋或篩選既有圖片。
3. 選取圖片後立即更新封面預覽與網址欄位。
4. 介面提醒仍需按「儲存修改」，才會寫入作品或觀點資料。

### 內文

1. 先將游標放到圖文編輯器中的目標位置。
2. 按工具列「從媒體庫插圖」。
3. 選取圖片後，插入目前游標位置，並在後方保留一個可繼續輸入的段落。
4. 圖片沿用既有替代文字、圖片說明與刪除功能。

## 共用選圖視窗

- 顯示縮圖、內容標題、作品／觀點、實際像素、檔案大小與使用狀態。
- 支援標題／檔名搜尋、作品／觀點篩選及分頁。
- 圖片使用 `contain`，禁止裁切文字或設計稿。
- 可取消而不修改內容。
- 選圖時不重新壓縮、不重新上傳、不產生 Storage 副本。

## 權限與安全

- 沿用 `/api/cms/media` 的管理員 UUID、Supabase JWT、MFA `aal2` 與 SQL owner 限制。
- 不在瀏覽器保存 JWT，不回傳原圖、Storage token 或金鑰。
- 不加入刪除、重新命名或跨使用者選圖能力。
- 登入失效、媒體索引不可用或圖片尺寸讀取失敗時，顯示可理解訊息，不改動表單。

## 驗收

- 封面可從媒體庫選擇，預覽與網址同步更新，儲存前有明確提醒。
- 內文圖片插入游標位置，不固定插在第一段或文末。
- 同一張圖片重用時，媒體庫總數不增加，Storage 不新增檔案。
- 原本「上傳新圖片」流程維持可用。
- 搜尋、篩選、分頁、取消與登入錯誤均安全處理。
- 測試、ESLint、TypeScript、production build 與 Vercel Preview 通過。
